# My Python Learning Journey

## 🎯 The Goal
Build a **Personal Productivity Suite** through 5 scalable projects.
Each project teaches new Python skills while building something useful.

---

## 🗺️ The Red Thread

```
Start Simple → Grow Complex
   ↓
Project 1: CLI Todo List (Python Basics)
   ↓
Project 2: Expense Tracker (Data Structures)
   ↓
Project 3: Weather CLI (APIs)
   ↓
Project 4: Web Todo List (Flask)
   ↓
Project 5: Personal Dashboard (Integration)
```

---

## 🏗️ Projects

### Project 1: CLI Todo List
**Focus:** Python fundamentals
- Start: Add/view 2 todos
- Grow: Full CRUD + file saving
- **Folder:** `project-1-todo/`

### Project 2: Expense Tracker  
**Focus:** Data structures & files
- Start: Track 3 expenses
- Grow: Monthly reports + categories
- **Folder:** `project-2-expenses/`

### Project 3: Weather CLI
**Focus:** APIs & external data
- Start: Show 1 city's weather
- Grow: Multi-city + forecasts
- **Folder:** `project-3-weather/`

### Project 4: Web Todo List
**Focus:** Flask web framework
- Start: Display todos in browser
- Grow: Full web CRUD app
- **Folder:** `project-4-web-todo/`

### Project 5: Personal Dashboard
**Focus:** Integration
- Start: Combine Projects 1-4
- Grow: Deployable web app
- **Folder:** `project-5-dashboard/`

---

## 📝 How to Use This Repo

1. Create a folder for each project
2. Start with the simplest version
3. Improve it step by step
4. Commit your progress to GitHub

---

## 🚀 Quick Start

```bash
# Clone this repo
git clone https://github.com/HaggeBear/My-Python-Tutorial.git
cd My-Python-Tutorial

# Start Project 1

# Create todo.py and start coding!
```
