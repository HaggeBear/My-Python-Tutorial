# Python Learning Journey: From Beginner to Full-Stack

## 🎯 Project Overview

This is your **personalized learning path** to master Python programming, with smooth integration of front-end technologies (HTML, CSS, JavaScript) when building interactive applications. You'll be guided by a **senior software engineer mentor** (that's me!) who follows strict pedagogical rules to ensure you **learn deeply** and **build independence**.

---

## 📚 Learning Philosophy

### The Snoopy Rule (Scaffolding Over Spoiling)
- ❌ **Never:** Complete production-ready code for your core assignments
- ✅ **Always:** Guiding questions, concept explanations, small snippets, and pseudo-code
- 🎯 **Goal:** You write the logic, I guide the thinking

### Our Teaching Framework
1. **Socratic Method:** I ask questions to help you discover solutions
2. **Incremental Milestones:** Small, validated steps before moving forward
3. **Full-Stack Awareness:** Python backend + HTML/CSS frontend integration
4. **Best Practices:** PEP 8, clean code, proper debugging techniques
5. **Encouraging Tone:** Warm, constructive feedback that builds confidence

---

## 🗺️ Learning Roadmap

### Phase 0: Hello, Debugger! ⚡
**Goal:** Learn to read errors and debug like a pro
- Understanding Python tracebacks
- Using `print()` for debugging
- Introduction to `pdb` and IDE debuggers
- **Project:** Fixing broken code snippets
- **Duration:** 1-2 sessions

### Phase 1: Pure Python Fundamentals (The Terminal Era) 🐍
**Goal:** Master variables, data types, loops, conditionals, and functions
- Basic I/O operations
- Data structures (lists, dictionaries)
- Function definition and scope
- **Project:** CLI Todo List Application
- **Duration:** 2-3 weeks

### Phase 2: Data Persistence & Organization 💾
**Goal:** Learn file I/O, data validation, and code organization
- Reading/writing CSV and JSON files
- Error handling with `try/except`
- Structuring code into modules
- **Project:** Personal Expense Tracker (local files)
- **Duration:** 2-3 weeks

### Phase 3: Static Frontend Basics 🎨
**Goal:** Learn HTML and CSS fundamentals
- HTML structure and semantics
- CSS styling and layout
- Responsive design basics
- **Project:** Personal Profile Page
- **Duration:** 1-2 weeks

### Phase 4: Python + Web Integration (Flask) 🌐
**Goal:** Connect Python backend to HTML frontend
- Flask framework basics
- Routes and request handling
- Jinja2 templating
- **Project:** Web-based Todo List or Expense Tracker
- **Duration:** 2-3 weeks

### Phase 5: External Data & APIs 🔗
**Goal:** Work with external data sources
- HTTP requests with `requests` library
- API response handling (JSON)
- Displaying external data in web app
- **Project:** Weather App or News Aggregator
- **Duration:** 2 weeks

### Phase 6: Databases (SQLite → PostgreSQL) 🗃️
**Goal:** Persistent data storage
- SQLite basics (built into Python)
- SQL queries and CRUD operations
- Database schema design
- **Project:** Database-backed Expense Tracker
- **Duration:** 2-3 weeks

### Phase 7: Testing & Deployment 🚀
**Goal:** Professional development practices
- Unit testing with `pytest`
- Local deployment with Flask
- Cloud deployment (Render, PythonAnywhere)
- **Project:** Deploy Weather App or Todo List
- **Duration:** 1-2 weeks

## 🎓 How to Use This Project

### For the Student (You!)
1. **Start at Phase 0** - Even if you're eager, debugging skills will save you hours of frustration
2. **Read the README** in each phase before starting
3. **Attempt exercises** before looking at solutions
4. **Ask questions** when stuck - I'm here to guide!
5. **Celebrate small wins** - Every concept mastered is progress

### For the Mentor (Me!)
- Follow the **MENTOR_GUIDELINES.md** strictly
- Use the **Socratic method** - ask questions, don't give answers
- Provide **scaffolding** - code skeletons, not complete solutions
- Validate each **milestone** before moving to the next
- Always **explain errors** - teach debugging, not just fixes

## 📞 Need Help?

When you're stuck:

2. **Try to identify** which line caused it
3. **Think about** what the code is trying to do

   - What you've tried so far

I'll guide you through the problem using questions and hints!
